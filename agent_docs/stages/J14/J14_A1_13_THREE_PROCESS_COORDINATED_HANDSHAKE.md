# J14-A1.13 三进程协调启动握手实验与归因总结报告

## 摘要
在 J14-A1.12 三进程架构（Driver Parent、UART Child、Feedback Bridge）验证中，稳态反馈时延虽已降至 P50 ≈ 0.55 ms、稳态 0 丢包，但发现存在启动阶段时序倾斜（Startup Skew）机制：UART Child 初始化仅需 ~50 ms 即开始 50 Hz 伺服循环并推流，而 Feedback Bridge 需约 240 ms 导入 ROS 2 依赖并完成节点构建，导致启动阶段出现 5 个丢失数据包及首帧 IPC Age 达 244.485 ms。

J14-A1.13 引入三进程确定性协调启动握手协议（PARENT_READY + BRIDGE_READY + CHILD_READY → SERVO_START）。硬件实机试验 R1（30 s，1500 周期）与 R2（60 s，3000 周期）在 `/dev/ttyUSB0` 上全通验证：
1. **启动阶段丢包彻底归零**：R1 与 R2 首个接收周期均为 `cycle_seq = 0`，启动阶段丢包为 0，稳态丢包为 0，全程 4500 周期 100% 完整交付。
2. **首帧反馈时延归零**：Cycle 0 Feedback IPC Age 从 A1.12 的 244.485 ms 骤降至 R1 的 **0.295 ms**、R2 的 **0.245 ms**（降低 99.9%）。
3. **稳态性能卓越**：Feedback IPC Age P50 ≈ 0.53-0.55 ms，P99 ≈ 1.15-1.21 ms，Max ≤ 32.8 ms；UART 物理写入 27,000 / 27,000 次 100% 成功，0 TX 超时。
4. **安全与清理合规**：6/6 轴本地暂停 ACK 确认，0 残留进程，串口干净释放。

至此，6PUS 真实实机的控制通信架构长尾根因全部排查闭环，架构级调试正式宣告圆满完成。
