# J6 Phase 3 首次运动安全审查

## 1. 审查范围与结论

本审查针对总装后的 6PUS Stewart 并联机构，评估现行 Phase 3“单轴移动 `20..40 steps`、其余五个执行器保持不动”的首次运动策略。这里的 `1 step = 0.025 mm`，因此现行首动幅度为 `0.5..1.0 mm`。

**审查结论：** 该策略不应作为闭链总装机构的默认首动策略。它可以作为经过额外约束分析和现场授权后的诊断性扰动试验，但不能等同于单电机台架测试，也不能假定其对平台是低风险或单自由度运动。首次总装运动应采用更小的分级位移、逐步观察和独立回程授权；在当前 Phase 2 机械 bottom 尚未确认的情况下，Phase 3 仍保持 `HOLD`，不得执行。

本文件只更新安全解释和建议，不修改控制代码、电机驱动、`geometry.yaml`、offset 或 J5 frozen 文件。

## 2. 对现行单轴策略的判断

### 2.1 “五轴固定”不是“五轴无影响”

在 Stewart 闭链中，六根执行器共同决定动平台的六自由度位姿。将一根执行器改变若干步、并让其余五根执行器保持目标值，会产生以下约束关系：

1. 动平台必须同时满足其余五根支链的长度约束，以及主动变化支链的新长度约束。
2. 这通常不是一个可独立观察的单腿自由运动；平台姿态可能发生耦合的升降、平移和倾斜。
3. 五个“固定”执行器仍承受平台运动带来的反力和侧向分量。位置保持并不等于力为零，也不等于球铰可以无限顺应。
4. 在低位、关节角接近边界、杆件不平行或局部 Jacobian 条件较差的位置，极小的长度变化也可能产生较大的内部载荷或使某个球铰先到达角度极限。
5. 若真实装配与软件锚点顺序、杆长或零位存在偏差，单轴扰动可能把装配误差表现为卡滞、扭斜或五轴被动跟随，而不是清晰的方向验证。

因此，单轴命令只代表“给闭链施加一个局部长度扰动”，不代表“只有一根腿在运动”。必须同时观察六轴反馈、平台姿态、球铰和结构反力迹象。

### 2.2 现行 `20..40 steps` 的风险等级

`20..40 steps` 等于 `0.5..1.0 mm` 的单腿长度变化。对一套尚未完成机械 bottom 实测、仍使用软件参考几何的总装闭链机构，这个幅度不应被称为无条件的“极小”。尤其当前 `q_park observed` 与软件 `STORAGE_PARK` 存在 `-1..-2 steps` 级静态差异，且机械 bottom 尚未确认，首动不应直接跨越 20 steps 的量级。

现行 `50 step/s` 应理解为速度上限，而不是已经证明对闭链首动安全的速度。即使平均速度低，结构接触、预紧释放或球铰碰撞仍可能在很短时间内出现。首动幅度和停止观察窗口应优先于追求一次完成往复。

### 2.3 工具行为的边界

现有 `run_j6_phase3_single_axis_micro_jog.py` 会执行单轴配置、前进、暂停确认、返回和再次暂停确认，并检查被观察轴的反馈单调性及回程误差。它能约束串口写入范围和报告格式，但不能从软件推导以下物理事实：

- 动平台实际运动方向是否为期望的 `+Z`；
- 五个保持轴的内部反力是否安全；
- 球铰是否接近角度或机械止挡；
- 杆件、线缆、平台或外部夹具是否发生干涉；
- 当前软件几何是否代表最终装配。

工具通过不等于闭链机械安全通过。尤其不能因为其余五轴没有运动写入，就把其余五轴视为“没有参与受力”。

## 3. 单电机台架测试与总装平台测试的区别

| 项目 | 单电机 / 独立台架测试 | 6PUS 总装闭链测试 |
| --- | --- | --- |
| 主要验证 | 通信、ID、寄存器、独立方向、单体行程 | 支链拓扑、平台耦合、姿态响应、间隙与载荷分配 |
| 约束数量 | 基本无其他支链约束 | 六支链共同约束同一个动平台 |
| 负载来源 | 电机和电缸自身摩擦/负载 | 重力、平台惯量、五轴保持反力、球铰侧向力、结构预紧 |
| 方向含义 | 电缸输出轴的正负方向 | 电缸方向与平台 `Z/X/Y/姿态` 响应的组合关系 |
| 失败表现 | 通信错误、独立卡滞、单体故障 | 平台倾斜、支链互相顶压、球铰卡边、杆件干涉、异常电流 |
| 可迁移结论 | 证明该电缸本身可读、可控 | 不能证明装配后闭链可单轴安全运动 |

六个执行器在装配前分别通过测试，只能支撑单体层面的证据。不能替代 A1-A6 映射、机械 bottom、支链间隙、实际杆长和总装受力状态的验证。

## 4. 推荐的首次运动策略

### 4.1 运动前置门禁

在任何真实动态命令之前，必须同时满足：

- Phase 2 物理 ID 映射记录已签字；
- `q_bottom_1..q_bottom_6` 已通过独立机械方式测得并与 `q_park observed` 分开归档；
- 机构无外部负载，动平台和各支链有可视观察空间；
- 急停可由现场人员立即操作，另有一名人员专门观察平台与球铰；
- 已记录只读基线：六轴 target、actual、current、fault、温度、限位和时间戳；
- 已定义本次试验的最大允许电流、位置残差和停止确认条件；不能仅依赖通用驱动阈值；
- 当前软件几何与硬件限位字段保持分离，不用试验临时改写配置绕过门禁。

当前 J6 状态中机械 bottom 仍为待确认，因此上述入口条件尚未满足，结论仍为 `HOLD`。

### 4.2 降低首动幅度并分级递增

建议将首次闭链扰动改为以下分级策略，供后续评审和工具设计使用：

| 级别 | 单次选定轴位移 | 换算长度 | 允许条件 |
| --- | ---: | ---: | --- |
| 首次探测 | `+/-2 steps` | `+/-0.05 mm` | 只做一个方向、立即停住并观察；不自动回程 |
| 第二级 | `+/-5 steps` | `+/-0.125 mm` | 首次探测无异常，完成全六轴和平台记录后另行授权 |
| 第三级 | `+/-10 steps` | `+/-0.25 mm` | 两级均通过，且无内部载荷或间隙异常 |
| 原计划上限 | `+/-20..40 steps` | `+/-0.5..1.0 mm` | 不得作为首动；需单独的闭链受力/间隙审查后才可考虑 |

首个 `+/-2 steps` 不是通过门槛，而是建立观察窗口的最小扰动建议。若驱动工具不能安全支持该步长或不能把前进与回程拆成两个独立授权动作，则不应直接运行现有 `20..40 steps` 接口，应先完成工具策略评审；本次不修改工具实现。

建议首动使用最低可验证速度。现行 `50 step/s` 可保留为后续阶段的硬上限，但不应自动视为首动的推荐速度；速度降级能力需要另行评审后再改代码。

### 4.3 前进、停止、回程必须分开

闭链首动不应把“前进后自动回到基线”视为一个不可分割的动作。推荐顺序为：

1. 记录静态基线并确认所有轴无故障、无明显电流。
2. 对一个选定轴施加 `+/-2 steps` 单向扰动。
3. 到达或超时后立即进入保持/停止状态，采集并检查六轴反馈和机械观察。
4. 只有在现场确认无卡滞、无异常载荷、无干涉后，才单独授权返回；返回仍需重新观察和确认。
5. 任何阶段出现异常，保持停止并执行现场安全处置，不自动重试、反向顶压或增大步长。

这样可以区分“前进造成的约束反应”和“返回动作造成的第二次约束反应”，避免自动回程掩盖第一次异常。

## 5. 首次运动的观察要求

### 5.1 六轴和驱动反馈

每一个前进、停止和回程阶段至少应归档：

- ID1-ID6 的 target 与 actual 原始 steps，以及每轴时间戳；
- 六轴 current、fault、温度、通信超时和停止确认；
- 被选轴的反馈单调性、到达误差和保持后的漂移；
- 未选五轴的 actual 是否出现非目标变化、反复追赶或异常波动；
- 每轴写入计数、暂停记录和完整写审计；
- 原始硬件限位与软件安全包络分开记录。

“其他五轴未发送运动写入”只能作为写入审计字段，不能作为机械无载荷证明。

### 5.2 平台、支链和环境观察

必须由现场人员同时记录：

- 动平台是否发生可见的升降、侧移、俯仰或横滚；
- 平台是否保持在安全范围内，是否出现突然跳变或扭斜；
- 六根推杆、碳纤维杆和球铰是否有卡边、擦碰、死挡或异常摆动；
- 相邻支链、导轨、线缆和外部夹具的最小间隙；
- 异响、弹性释放、结构振动、连接件松动或杆件弯曲迹象；
- 急停后平台和支链是否停止，是否存在继续爬行或回弹。

只看编码器位置而不看平台和关节，不能形成 Phase 3 机械 PASS。平台姿态最好使用独立可追溯的量具或标记观察；IMU 或软件姿态只能作为辅助证据，不能替代间隙和机械止挡检查。

### 5.3 立即停止条件

出现以下任一情况，立即停止当前动作并保持 `HOLD`：

- 任何方向与现场预期不一致；
- 被选轴不动而其他轴或平台明显受力、跳动或倾斜；
- 任一轴 fault 非零、current 突增、持续不降或通信丢失；
- 反馈不单调、目标与实际持续发散、停止后仍漂移；
- 球铰接近角度极限，杆件、线缆或平台发生干涉；
- 听到异响、出现卡滞、结构弹性释放或急停确认失败。

停止后不得通过提高限位、改 offset、修改几何或重复发送目标来“恢复通过”。

## 6. 从单轴扰动过渡到协调运动

### 6.1 单轴试验的结论边界

即使六个轴都完成小幅单轴观察，最多只能支持以下结论：

- 电机 ID 与物理支链对应关系在现场可追溯；
- 指定电缸的原始反馈方向和小范围可动性已观察；
- 在给定位置和给定小扰动下没有发现明显干涉。

它不能直接证明：平台的 `+Z` 方向、完整 IK/FK 正确、协调轨迹稳定、HOME/PARK 可达或整个工作空间安全。

### 6.2 推荐的协调运动过渡顺序

建议采用以下独立门控，不从单轴首动直接跳到大范围 Cartesian motion：

1. **Phase 3 诊断扰动完成：** 六轴分别完成分级小步测试，前进和回程记录完整，所有现场观察 PASS。
2. **协调执行器空间试验：** 使用经过审查的、与机构约束一致的六轴目标向量，所有轴以很小的同步增量动作；每轴增量不超过已通过的单轴级别，先验证跟随和载荷分配。
3. **PARK/HOME 独立门控：** 只有协调执行器空间试验通过，才另行审查低速 HOME/PARK 的机械可达性、水平度和间隙。
4. **小幅笛卡尔试验：** 只有 HOME/PARK 和几何入口条件满足后，才进入小幅 Heave、X/Y 或姿态试验；每次只测试一个经过验证的自由度并返回已确认工作基准。

协调向量必须来自已审查的实际装配映射和几何假设。当前 `geometry.yaml` 仍是待最终装配确认的模型，且机械 bottom 未确认，因此当前不能授权第 2 步及以后步骤。

### 6.3 过渡门控摘要

| 门控 | 必须具备的证据 | 当前状态 |
| --- | --- | --- |
| Phase 2 -> 首次扰动 | 映射签字、`q_bottom`、安全观察安排 | `HOLD`：机械 bottom 缺失 |
| 首次扰动 -> 分级增量 | 六轴反馈、平台/球铰观察、无异常电流与故障 | 未开始 |
| 分级增量 -> 协调执行器空间 | 六轴方向和耦合反应可解释，几何假设经审查 | 未授权 |
| 协调执行器空间 -> HOME/PARK | 协调稳定、停止可确认、间隙和水平度证据 | 未授权 |
| HOME/PARK -> Cartesian | 工作基准和最终几何入口条件满足 | 未授权 |

## 7. 建议的政策结论

1. 将现行 `20..40 steps` 从“首动默认值”降级为后续可评审的上限范围。
2. 将 `+/-2 steps` 作为首次闭链扰动的建议起点，按 `2 -> 5 -> 10 steps` 分级；每级必须单独审查。
3. 删除或禁用“前进后自动回程”的首动假设，前进、停止检查和回程分别授权。
4. 将“其他五轴零写入”与“其他五轴无机械受力”明确区分，六轴反馈和平台观察必须同时保留。
5. 在现有工具和门控逻辑完成评审前，不执行真实 Phase 3；本文件不提出代码修改，代码变更需另立审查任务。
