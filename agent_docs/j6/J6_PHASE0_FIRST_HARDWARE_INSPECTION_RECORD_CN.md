# J6 Phase 0 首次实机检查记录

本记录用于 J6 机械装配完成后的首次实机调试会话。每次会话填写一份，
并附上所引用的照片或测量文件。所有测量值和现场观察必须如实记录。

Phase 0 是**不上电、无运动门禁**。本阶段不授权接通 24 V 电源、不授权
电机通信、编码器读取、电机写入、HOME/PARK 或任何笛卡尔运动。基于编码器
的零位映射只能在后续 READ_ONLY 门禁通过后执行。最终 IMU 外参和杠杆臂
验收属于后续调试阶段。
