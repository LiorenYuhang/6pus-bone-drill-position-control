## 4. PARK 参考定义

### 4.1 运行定义

- `PARK` 在本记录中的运行定义为：测试结束后使机构回到最低停放参考位置，并在电机断电后由机械结构保持。
- 电机断电机械保持是停放状态的保持方式；本记录没有执行 PARK，也没有验证机械止挡或下限位。
- 后续测试记录如写“通过 PARK 返回最低点”，应理解为返回软件停放参考，不得自动解释为已到达机械极限。

### 4.2 软件 STORAGE_PARK 基准

当前软件 `STORAGE_PARK` 原始步数基准为：

```text
[0, 0, 0, 0, 0, 0]
```

该向量是软件参考定义，用于停放状态记录和比较；不等同于实测机械 bottom，也不授权修改任何几何或偏置参数。

## 6. 软件停放参考与机械 bottom 的区别

必须保持以下边界：

1. 软件 `STORAGE_PARK = [0,0,0,0,0,0]` 是软件停放参考值。
2. `q_park observed = [0,0,-2,-1,-2,-2]` 是当前 READ_ONLY 静态反馈观测值。
3. 机械 bottom 需要在断电 / 无运动条件下由现场确认机械止挡、见证标记或独立测量得到。
4. 当前记录没有测量或确认机械 bottom，因此不得将 `q_park observed` 写入 `q_bottom`，不得添加位置补偿，也不得据此修改 `geometry.yaml` 或 offset。
